# Дитли

Внутренний сервис коротких ссылок. Менеджер заводит проект, кладёт в него ссылки и смотрит, сколько раз по ним перешли. Клиент получает короткую ссылку и в сервис не входит.

Сервис — один процесс со своей базой SQLite. Отдельная база данных не нужна.

## Что нужно

Python 3.11 или новее.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Базовый адрес короткой ссылки

Короткая ссылка — это базовый адрес плюс код. Домен в программу не зашит: его задают настройкой. Когда компания купит домен, его вписывают в ту же настройку.

```bash
export DITLY_BASE_URL=http://127.0.0.1:8000
```

Адрес без пути в конце. Пример будущей настройки:

```bash
export DITLY_BASE_URL=https://go.example.com
```

Этот адрес должен открывать тот же сервис. Переход идёт на `БАЗОВЫЙ_АДРЕС/код`.

## Первая учётка

Открытой регистрации нет. Первую учётку создают при установке. Команда дважды спросит пароль.

```bash
python -m ditly create-user anna
```

Для скрипта пароль можно передать переменной `DITLY_PASSWORD`, чтобы он не светился в списке процессов.

Следующие учётки заводит уже вошедший пользователь: пункт «Новая учётка». Новая учётка сама по себе чужих проектов не видит.

## Запуск

```bash
export DITLY_BASE_URL=http://127.0.0.1:8000
python -m ditly serve
```

Откройте http://127.0.0.1:8000 и войдите. База лежит в `data/ditly.sqlite`. Ключ сессии — в `data/secret.key`. Если удалить ключ, всем придётся войти снова.

Чтобы слушать не только этот компьютер:

```bash
export DITLY_HOST=0.0.0.0
export DITLY_PORT=8000
python -m ditly serve
```

Если меняете порт, поменяйте и `DITLY_BASE_URL`.

## Как пользоваться

1. Войдите и создайте проект. Создатель сразу управляет доступом.
2. Добавьте ссылку: пометка и длинный адрес. Сервис покажет короткую ссылку, её можно скопировать.
3. Откройте статистику. Видно, сколько переходов и в какие сутки по московскому времени. Автоматические заходы по умолчанию скрыты, их можно вернуть фильтром.
4. Ссылку можно переименовать пометкой, сменить длинный адрес, выключить или удалить. Выключенная ссылка никуда не ведёт.
5. Чтобы открыть проект коллеге, у коллеги уже должна быть учётка. Роли: просмотр, редактирование, управление доступом. Редактирование включает просмотр. Управление доступом включает редактирование.

Чужой проект в списке не появляется.

## Для разработчиков компании

Проверка «кто вошёл» собрана в `ditly/identity.py`. Проекты, роли и ссылки хранят только идентификатор пользователя. Чтобы подключить систему учёток компании, замените этот модуль. Сейчас она не подключена.

Сутки на экране статистики считаются по часовому поясу Europe/Moscow. Время перехода хранится точно.

У перехода всегда есть время и признак автоматического захода. Источник, устройство, страна и ключ посетителя заполняются, когда их удалось получить. Сырой IP не хранится. Страна определяется только если указана локальная база GeoIP и установлен пакет `maxminddb`:

```bash
export DITLY_GEOIP_DB=/путь/к/GeoLite2-Country.mmdb
```

За обратным прокси можно доверять первому адресу из `X-Forwarded-For`:

```bash
export DITLY_TRUST_PROXY=1
```

Проверка сценария «учётка, проект, ссылка, переход, фильтр автоматических заходов»:

```bash
python -m unittest discover -s tests -v
```
